### C++-Module 00 Namespaces, classes, member functions, stdio streams, initialization lists, static, const, and some other basic stuff
Welcome to C++

Learning the basics of the coding language, but obviously with a big step up, since we have already learnt the basics in C.  
Now let's throw most of what we learnt away, and try some new things aye?

Inside this folder, are two completed exercises: Megaphone and PhoneBook.  
Megaphone is basically the Hello World exercise in which we would take a given string and CAPITALIZE all its alphabetical contents.  
PhoneBook is a simple program that introduces us to Classes and Members. We obviously need to remember things!
